# Şoför Sefer Takip – Modern Sürüm

Bu sürüm ana ekranı daha modern, okunabilir ve telefona uyumlu hale getirir.

Özellikler:
- Modern mavi üst başlık
- Büyük ve belirgin “Yeni Sefer Ekle” butonu
- Sefer sayacı
- Son seferler kart görünümü
- Sefer ekleme formu
- Aylık özet
- Seferi uzun basarak silme
- Veriler telefonda saklanır

GitHub Actions ile `app-debug.apk` üretilebilir.
